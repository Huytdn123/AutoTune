# CÔNG NGHỆ DỰ ÁN VIRTUAL TUNE

## 1. Backend
- **Ngôn ngữ**: Java 25
- **Framework**: Spring Boot 3.4.0
- **ORM / Persistence**: Spring Data JPA, Hibernate
- **Build Tool**: Maven (Maven Wrapper `mvnw`)

## 2. Frontend
- **Runtime & Package Manager**: Node.js v22.x LTS, npm 10.x
- **Framework**: React 19
- **Build Tool**: Vite 6
- **3D WebGL Engine**: Three.js (^0.170.x)
- **Icons**: Lucide-React
- **HTTP Client**: Axios

## 3. Database
- **Hệ quản trị CSDL**: Microsoft SQL Server 2022
- **Driver kết nối**: Microsoft JDBC Driver for SQL Server (`mssql-jdbc`)
- **Cổng kết nối**: 1433
- **Bảng mã**: Vietnamese_CI_AS (UTF-8 Unicode)

## 4. Khởi chạy
- **1-Click**: `start-dev.bat` (tự động chạy cả Backend port 8080 và Frontend port 5173)
